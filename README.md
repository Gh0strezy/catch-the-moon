# Поймай Луну

Кооперативный кликер для Roblox. На крыше обсерватории игроки вместе заполняют шкалу из 18 нажатий. Каждый, кто успел поучаствовать, получает собственную Луну и звёздную пыль. Играть можно и одному.

## Запуск

Скачайте файл **[CatchTheMoon.rbxlx](CatchTheMoon.rbxlx)** через **Download raw file** на GitHub или откройте его из локальной копии репозитория. В Roblox Studio выберите **File → Open from File**, откройте плейс и нажмите **Play (F5)**. Для совместного теста запустите режим **Server & Clients** с двумя игроками.

Нажимайте на Луну, на кнопку **«Ловить Луну»**, пробел или правый триггер геймпада. **«Атлас»** показывает количество пойманных экземпляров и шансы выпадения. **«Удача +»** открывает улучшение за пыль. Три обычные Луны приносят достаточно пыли для первого улучшения.

## Как работает удача

| Луна | Редкость | Шанс при ×1 | Пыль |
| --- | --- | ---: | ---: |
| Меловая | Обычная | 58% | 8 |
| Приливная | Необычная | 27% | 16 |
| Орхидея | Редкая | 11% | 36 |
| Янтарная | Эпическая | 3,5% | 80 |
| Корона | Легендарная | 0,5% | 200 |

Каждое улучшение добавляет ×0,25 к удаче, максимум — ×4. Если базовый шанс получить Луну заданной редкости или лучше равен `p`, улучшенный шанс равен `1 − (1 − p)^удача`. У каждого участника свой бросок. Суммарная вероятность всех пяти результатов равна 100%.

В опубликованном плейсе сервер сохраняет пыль, удачу и коллекцию через DataStore. В Studio прогресс действует до конца тестовой сессии. Кнопки внутри плейса тратят только заработанную пыль.

## Работа с исходниками

Логика выпадения и баланс лежат в `src/shared/MoonCatalog.luau`, раунды и сохранения — в `src/server`, интерфейс и объёмная Луна — в `src/client`. Готовая сцена находится в `world/Observatory.rbxmx`.

Из корня репозитория соберите файл для Studio через Rojo 7.7.1:

```sh
rojo build default.project.json -o CatchTheMoon.rbxlx
```

Для работы с кодом в реальном времени запустите `rojo serve` и подключите плагин Rojo в тестовой копии Studio. При изменении генератора крыш и обсерватории сначала выполните `lune run tools/build-observatory.luau` (Lune 0.11.1), затем пересоберите плейс.

Проверка баланса и раундов выполняется командой `luau tests/gameplay.luau`. Сценарий `tests/studio-smoke.luau` предназначен для Studio CLI в режиме `RunScript` с локальным файлом плейса. Он проверяет появление интерфейса, три поимки и покупку улучшения.
