# Catch the Moon — орбитальная станция

Откройте [CatchTheMoon-Station.rbxl](CatchTheMoon-Station.rbxl) в Roblox Studio и нажмите F5. Игрок появляется на восьмилучевой звезде под главным телескопом. Восемь мостов ведут к персональным причалам. Назначение базы игроку, покупки и работу лассо предстоит подключить к серверным системам.

[Точки интеграции и пример установки этажа](DESIGN_INTEGRATION.md) · [Атлас участков](WORLD_ZONES.md)

### Сборка и синхронизация станции

В корне репозитория выполните:

```sh
lune run tools/build-station.luau
rojo build default.project.json -o CatchTheMoon-Station.rbxl
rojo serve default.project.json
```

Генератор рассчитан на Lune 0.11.1, сборка — на Rojo 7.7.1. Готовые модели включены в Git. После изменения модулей геометрии повторите первую команду. Изменения Luau-скриптов Rojo подхватывает сразу. В Studio откройте Plugins → Rojo → Connect, адрес localhost и порт 34872. Для установки совместимого плагина используйте `rojo plugin install`.

Для передачи результата на другой ноутбук пересоберите плейс и включите в коммит исходники и полученные модели. Основной проект Rojo собирает станцию. Предыдущий лунный мир сохранён ниже со своим файлом проекта.

## Архивный плейс «Лунный меридиан»

Откройте **[CatchTheMoon-Meridian.rbxlx](CatchTheMoon-Meridian.rbxlx)** в Roblox Studio и нажмите **Play (F5)**. Для загрузки с GitHub используйте **Download raw file**. Для теста вдвоём выберите **Server & Clients** и двух игроков.

С крыши можно выйти по двум боковым рампам. Западная ведёт к Пассажу Сирены, восточная — к посту картографа. Обе тропы выходят на северный вал Моря Тени. [Атлас мира и постоянные адреса участков](WORLD_ZONES.md).

## Первый заход

Персонаж появляется на крыше обсерватории. Ходьба, прыжки и камера используют обычное управление Roblox. Подойдите к подсвеченной станции и воспользуйтесь подсказкой взаимодействия — на клавиатуре это **E**.

1. **Телескоп** выбирает цель по вашей удаче. Дождитесь, когда белый указатель войдёт в зелёную зону, и нажмите кнопку поимки, пробел или правый триггер. После трёх промахов планета уходит. Рядом с телескопом напарники могут помогать друг другу после первого собственного идеального попадания.
2. **Рюкзак** показывает запас планет, шансы и доход. В галерее найдите табличку со своим именем, подойдите к одной из трёх витрин и выберите планету. Можно заменить экспонат или вернуть его в рюкзак. Витрины видны другим игрокам.
3. **Мастерская удачи** повышает шанс редких находок за игровые доллары. **Станция скорости** повышает скорость бега. **Тренажёр силы** расширяет окно идеального попадания. Удерживайте кнопку взаимодействия для каждого подъёма штанги.

## Стартовый баланс

| Планета | Шанс при удаче ×1 | Идеальных попаданий | Награда | Доход за 5 секунд на витрине |
| --- | ---: | ---: | ---: | ---: |
| Меловая | 58% | 2 | $8 | $1 |
| Приливная | 27% | 3 | $15 | $3 |
| Орхидея | 11% | 4 | $32 | $7 |
| Янтарная | 3,5% | 5 | $70 | $15 |
| Корона | 0,5% | 6 | $150 | $32 |

Первое улучшение удачи стоит $24, скорости — $20. Удача растёт с ×1 до ×4, скорость — с 16 до 36 студов в секунду. Первые три подъёма штанги повышают силу на один уровень. На десятом уровне зелёная зона занимает 38% шкалы вместо стартовых 16%.

Доход начисляется автоматически за время в игре. В опубликованном плейсе сохраняются доллары, улучшения, коллекция и выбранные экспонаты. Пыль из первого прототипа переносится в доллары в соотношении 1:1. В Studio каждый тест начинается с новой коллекцией.

## Исходники и сборка

Баланс находится в `src/shared/MoonCatalog.luau`. Сервер обслуживает станции, ловлю, витрины и сохранения в `src/server`. Интерфейс и внешний вид цели находятся в `src/client`. Модель стартовой зоны лежит в `world/Observatory.rbxmx`.

```sh
# После правок геометрии (Lune 0.11.1)
lune run tools/build-observatory.luau
lune run tools/build-world.luau

# Сборка места (Rojo 7.7.1)
rojo build meridian.project.json -o CatchTheMoon-Meridian.rbxlx

# Проверка баланса, тайминга, витрин и переноса прогресса
luau tests/gameplay.luau
```

Для живой синхронизации архивной карты используйте `rojo serve meridian.project.json` и плагин Rojo в тестовой копии. `tests/studio-smoke.luau` запускается через Studio CLI с задачей `RunScript` и локальным файлом новой сборки.

### Окружение

Геометрия павильонов, причалов и дальнего плана находится в `tools/world`. Lune сохраняет модель `world/Meridian.rbxmx` и обновляет атлас. Настройки неба, атмосферы и постобработки «Меридиана» находятся в `meridian.project.json`. Изменения оформления делайте в этих исходниках или переносите из Studio в соответствующий модуль перед сборкой.

Нативный Terrain хранится в `world/LunarTerrain.rbxm`. Он включён в Git, поэтому для сборки плейса на MSI и Fedora достаточно Rojo. Для изменения высот, троп, палитры грунта или положения площадок отредактируйте `tools/world/landscape.luau` и `zones.luau`. На компьютере со Studio, Python 3 и Lune выполните `python tools/bake-terrain.py --studio "<путь к RobloxStudioBeta.exe>"`, затем пересоберите мир. Для Lune вне PATH можно указать `--lune "<путь к lune>"`.

Проверка `tests/world-smoke.luau` в Studio CLI читает реальные воксели восьми участков, проверяет перепады высот на семи маршрутах и проводит персонажа от телескопа через обе рампы. Перед запуском каждого теста скопируйте сборку во временную папку.

```text
RobloxStudioBeta.exe --task RunScript --localPlaceFile "<абсолютный путь к копии.rbxlx>" --runScriptFile "<абсолютный путь к тесту.luau>" --outputFile "<путь к журналу>" --quitAfterExecution
```

Предыдущая сборка крыши сохранена в `CatchTheMoon-Observatory.rbxlx`.
